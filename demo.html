Во что обошлась ваша сессия — и на чём утекли деньги

Перетащите файл сессии Claude Code. Разбор идёт прямо в этой вкладке: файл никуда не загружается, аккаунт не нужен.

Перетащите сюда файл .jsonl

Можно несколько файлов или сразу всю папку projects — покажем, что повторяется из сессии в сессию.

Выбираете папку? Браузер спросит «Загрузить файлы на сайт?» — это его стандартный вопрос. Файлы всё равно остаются в этой вкладке.

🔒Файл не покидает браузер. Страница не отправляет ни одного сетевого запроса — можно отключить интернет и проверить.
Где лежит этот файл?

Claude Code пишет каждую сессию в отдельный файл .jsonl:

Windows: %USERPROFILE%\.claude\projects\
macOS и Linux: ~/.claude/projects/

Внутри — папка на каждый проект, в ней файлы с именами вида a1b2c3d4-….jsonl. Берите самый свежий, несколько или всю папку projects целиком.

Папка не видна в окне выбора? Она скрытая. На Mac нажмите Cmd+Shift+G и вставьте ~/.claude/projects (или Cmd+Shift+. — покажет скрытые папки). На Windows вставьте %USERPROFILE%\.claude\projects в строку адреса окна выбора.
