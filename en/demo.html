Where do I find this file?

Claude Code writes every session to its own .jsonl file:

Windows: %USERPROFILE%\.claude\projects\
macOS and Linux: ~/.claude/projects/

Inside there's a folder per project with files named like a1b2c3d4-….jsonl. Take the latest one, several, or the whole projects folder.

Can't see the folder in the file dialog? It's hidden. On a Mac, press Cmd+Shift+G and paste ~/.claude/projects (or press Cmd+Shift+. to show hidden folders). On Windows, paste %USERPROFILE%\.claude\projects into the dialog's address bar.
