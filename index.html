Счётчики показывают «сколько»

Есть бесплатные инструменты, которые красиво рисуют график трат. Но на вопрос «что именно сожгло деньги» они не отвечают.

Причина спрятана в логах

Один и тот же файл в контексте снова и снова, дорогая модель на простой задаче, повторы после ошибок. Всё это есть в логах, но вручную их никто не разбирает.

Почему это стало острее сейчас. 24 августа 2026 года Cursor перешёл на оплату по токенам. Огромная аудитория впервые видит счёт, который не понимает. Cursor поддержим в следующих обновлениях: начинаем с Claude Code, по нему данные точные.

А если у вас подписка? На Claude Pro или Max счёта нет, зато лимит кончается к обеду. Причины те же самые: разрослась переписка, модель ходит по кругу, фоновые задачи работают без вас. Их и ищем.

Как это работает

Всё происходит на вашем компьютере: логи никуда не отправляются.

  1. Читает локальные логи

    Claude Code и Codex пишут историю сессий на диск. OpenRouter отдаёт данные по вашему ключу. Cursor подключим последним.

  2. Приводит всё к одной схеме

    Каждое событие превращается в единую запись: модель, токены, кэш, шаг, проект, стоимость и пометка точности.

  3. Прогоняет десять проверок

    Каждая проверка ищет свою причину, по которой счёт растёт незаметно. Проверки написаны один раз и работают для всех инструментов сразу. Все десять уже работают в демо для Claude Code.

    Что модель перечитывает
    • Длина переписки
    • Повторно открытые файлы
    • Картинки в переписке
    • Скидка на перечитывание
    Как поставлена задача
    • Самая дорогая просьба
    • Ошибки и повторные попытки
    • Работа без результата
    Модель и настройки
    • Размышления модели
    • Дорогая модель для мелочей
    • Забытые фоновые процессы

  4. Отвечает: почему и что сделать

    Вы получаете причину, сумму и конкретное действие. Уже сейчас — в браузере по одной сессии или в терминале по всем сразу. Следом — скилл, чтобы спрашивать прямо в Claude Code.

Чем отличается от обычных счётчиков

Объясняет, а не считает

Сумму сегодня показывают бесплатно. Мы отвечаем на вопрос, который остаётся после неё: почему так вышло.

Одна картина на все инструменты

Одна схема и общие правила вместо отдельного инструмента под каждого провайдера. Новый адаптер сразу получает все десять проверок.

Данные остаются у вас

Анализ идёт локально, без регистрации. Логи не покидают компьютер.

Честно про точность

У каждой цифры есть пометка: точная или оценочная. Для Cursor полной картины локально нет, и мы прямо так и пишем.

Открытый код на GitHub

Код открыт по лицензии MIT. Консольная версия уже работает и бесплатна. Следом — скилл для Claude Code и MCP-сервер. Платное облако появится позже, когда будет что в нём хранить.

Автор разбирает инциденты

Одиннадцать лет поиска узких мест и разбора сбоев. Правила диагностики строятся на этом опыте, а не на красивых графиках.
